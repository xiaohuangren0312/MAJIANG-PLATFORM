# S2 / S3 历史数据 Demo

展示端已使用两季真实历史数据。S2 常规赛 80 场、S3 常规赛 108 场；阶段榜单作为原表积分的快照显示。半决赛及决赛的个人对局明细尚未导入。

使用 build-history.py 从 design/history-analysis/S2-cells.json 和 S3-cells.json 生成 site/data.json。只导出比赛字段，不导出报名、内部备注、身价与拍卖资料。旧 build-public-data.js 仍为虚构测试数据生成器，运行会覆盖当前 data.json；历史版应使用 build-history.py。

明细里的 PT 原值不改写。同点采用均分奖金，个人统计中的同位次数按名次均分。别名未确认时不合并，匹配不到队伍显示待核对，因此明细重算榜可能不同于首页源表榜。原表 PT 与换算基础分的差额仅作待核对调整展示，不声称判罚原因已确认。役满显示未采集。

S3 日期不是按行递增，其中第 107 行为 2026-05-28，晚于第110行的2026-05-27。保留原日期；列表及走势按日期排序。页面半庄序号按源行生成用于浏览，不代表原表已有正式比赛编号；桌号和开赛时间未补造。

验证：两季明细数 80/108；个人出场总计 320/432；S2、S3 冠军快照分别为银河蘸酱238.5和棒棒～给我棒棒～225.0；浏览器完成切季和个人榜查看。当前只更新独立展示端，管理端仍是独立示例数据，没有共享后台。
