# MAJIANG-PLATFORM 第一版需求与原型

## 已确认范围

- 本地线下立直麻将赛事，支持个人赛、战队赛。
- 管理后台以终局战果录入为核心，提供赛事、选手、战队和计分规则管理。
- 展示端适配电脑、手机，正式版采用可添加到手机桌面的 PWA；不做原生安装包。
- 开发与生产隔离；服务端代码、业务数据、日志、缓存及备份统一在 /data。

## 计分默认值

来源：https://m-league.jp/about/ 第六章，核实于 2026-09-05。
25000 起始、30000 返还，每 1000 点折算 1 积分。最终顺位加分 +50/+10/-10/-30（已包含头名奖励，不再重复加算）。同点平分所占顺位加分，三人同分的 0.1 分余数按起家顺序分配。负终局点数允许。

示例：41600/30000/20000/8400 -> +61.6/+10.0/-20.0/-51.6。
录入采用已经裁定、分配完终局供托的最终点数，默认总和应为 100000；供托未结算时禁止发布。处罚使用独立积分调整和原因，不修改终局点棒总数。

规则管理：起始点、返点、四个最终顺位加分、同分处理（平分或起家优先）、处罚配置、榜单资格条件。默认原始积分保留一位小数，使用整数 0.1 积分存储运算。自定义非零和规则允许，但应提示理论总积分，不强行归零。

规则版本不可覆盖历史；对局在创建时固定版本，发布后保留规则快照。修改生成新版本，历史重算是单独操作，需要范围预览和审计记录。

## 核心业务

- 赛事下有赛季/阶段、报名、桌次与半庄；个人赛记录个人积分，战队赛同时记录选手当场积分和当场所属队伍的贡献。
- 战队成员归属按参赛时快照保存，转队不改变历史得分；不同赛事和阶段的排行榜不能混算。
- 成绩包含四名不同选手、起家座次、最终点数、规则版本、处罚、状态及修订号。
- 草稿 -> 待审核 -> 发布；草稿不进入公开榜单。第一版允许具备权限的管理员录入并发布，后续可启用录入员与审核员分离。
- 更正保留原版本、修改原因和操作者；取消成绩不硬删除。并发修改检查版本；重复发布不重复计入。
- 榜单仅统计有效已发布结果；默认按总积分降序、积分相同并列展示，资格场数及额外决胜条件另行配置，不能借用单桌同分规则。
- 管理角色：管理员、录入员、审核员；观众无须登录。正式服务必须在服务器端认证授权和重新计算积分。

## 展示端与 PWA

赛事概览、赛程赛果、个人榜、战队榜、选手/队伍详情。个人赛隐藏战队榜入口。
正式 PWA 需要 HTTPS、Web App Manifest、应用图标和适当缓存策略；安卓与 iOS 使用各自浏览器的添加到桌面入口。公开成绩优先联网获取，离线内容显示缓存时间和状态；后台不允许离线发布或缓存私密 API 响应。

## 交付状态

本目录 index.html 是无需构建的响应式交互原型，使用虚构选手、队伍和示例战果。支持榜单切换、编辑点数、同分计分、规则新版本、草稿与演示发布，刷新后重置。未连接数据库、未实现登录、未安装到桌面、未部署到生产；不要录入真实业务数据。
本原型默认展示战队赛及其个人榜；正式产品还需实现赛事创建/类型切换、成员管理、审核权限、历史更正和比赛详情。

## 验收重点

正常分数、负分、两/三/四人同分、总点数异常、重复选手、处罚原因、规则版本冻结、重复发布和并发更正。移动端成绩输入可操作，榜单可读；真实持久化和权限必须独立验证。
