# 独立组队选人插件

更新：2026-09-16。Django app `team_draft`，独立活动与审计；仅接入开发环境，未推送 Git、未发布生产。

## 入口
- 活动首页：`/draft/`；活动：`/draft/<UUID>/`。
- 管理员同屏主持，教练在同一地址登录后进入手机操作，观众仅在管理员明确公开后免登录只读。
- 创建不自动绑定赛事；管理员手动关联未归档、未排比赛的普通团体赛事。配置从“编辑配置/更多”进入。
- 登录支持安全的同站 next 返回；两秒轮询，网络中断不自动 PASS，恢复后读取服务端状态。

## 规则和一致性
免费一选；重选冲突由服务端 Roll，同点最高者重掷，落选补选。第二轮随机抽人、按配置队伍顺序轮流报价/PASS，首个响应队按已处理选手轮换。PASS 不可在同一选人阶段重入；第三轮重置。管理员确认后才扣预算和入队。第三轮有报价锁定最终价格，可选择接收队；无有效报价允许非负自定价格，包括0。

预算、含教练容量、候选归属及正式选手身份、队伍状态、账号权限、活动版本、当前 lot 和重复提交均由服务端校验。活动先锁、赛事后锁；名单、预算、状态、双方审计同事务。教练账号不因此获得赛事管理权限。

## 结束、纠错和清理
最终检查使用30分钟签名预览，绑定操作者、活动与赛事版本。无第三轮候选直接进入最终检查。所有队已满时可明确列出未分队候选后结束；有空位仍须完成分派，不能超员或负预算。满员导致当前无报价 lot 无法分派时也可检查结束。结束只冻结选人快照，不归档赛事，后续赛事名单变化不重写最终阵容。

最小撤销范围：仅最后一次选人操作（配置、开始、提交、公布、Roll、轮转、报价/PASS、成交/分派）。先展示影响，再确认；无需原因。恢复名单、预算和流程，活动/赛事 revision 只增不减，审计保留。后续操作使旧预览失效；赛事外部 revision 或完整文档变化阻止回退。创建、关联、发布、解除、结束及撤销本身不可撤销；不提供连续回退，旧版缺少完整快照的审计不能撤销。

准备中可解除关联（清配置），结束后可解除关联（保留最终快照和所有审计），进行中不可解除。FK继续 PROTECT；测试赛事清理先给出“结束并解除关联”的明确错误，避免500。解除后仍需遵守赛事原有“测试、已归档、总管理员、备份”清理规则。活动及审计不提供硬删除；账号不清理。

## 大屏、手机与历史
墨黑、象牙白、朱红同屏展示：完整选手介绍、起拍价、报价和响应状态；教练单列、默认六个文字成员格（容量可配），实时预算与完整名单；复用品牌Logo/队标，没有人物头像和倒计时。第三轮采用简洁选队、价格、成交后人数余额预览。手机教练操作置于展示之前。

候选的历史身份由管理员逐来源明确选择ID，不按同名猜测。历史赛事可切换，展示各阶段场数、净PT、场均PT和平均顺位，未知保留未知；没有关联显示“暂无历史成绩”。只展示公开历史源，源撤下即不再投影；不修改任何历史数据。

## 发布与隐私
新建及现有私有活动不会自动公开。“更多”中显式公开/撤下，可在结束后维护。未公布一选只返回提交进度和本人选择；观众和其他教练无选择明细。非管理员响应无教练账号ID/用户名、完整赛事快照。页面失去访问权会清屏提示登录。所有修改重新校验权限，前端隐藏不代替后端保护。

## 验证与限制
详见 `design/TEAM-DRAFT-PROGRESS.md`。测试使用独立 `test_hql_draft_finish`，真实并发专项另用 `test_hql_draft_concurrency`；不占用主任务 `test_hql_dev`。后端回归与真实浏览器证据分开记录。

当前为两秒轮询，并非WebSocket；未验证真实多台物理手机同时在线。撤销不支持任意历史步骤/连续回退；完成后不提供重开。临时验收记录私有留存供审计，不删保留账号或活动。
