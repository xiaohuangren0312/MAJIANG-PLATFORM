# 欢雀楼赛事 · 独立观众展示端设计

2026-09-05；与管理端 v3 设计共同组成产品设计。此前 v3 的榜单属于管理工作台，不应作为最终观众界面。

## 两个明确入口

- 管理端：赛事创建、队伍/选手报名、排赛、录入、规则、结算、审核和权限。原型在 `../v3/index.html`。
- 观众端：本目录 `site/index.html`，独立布局和导航；只读浏览公开信息，不含录入、规则修改、阶段结算、报名编辑或管理按钮。
- 正式路由建议为公众 `/`，管理 `/admin` 或独立管理子域；管理端受服务端认证授权保护，不能只靠“藏按钮”。

## 页面设计

| 页面 | 内容与操作 |
| --- | --- |
| 赛事首页 | 赛事选择、赛事视觉区、公开完成场数、参赛人数/队伍数、役满次数、最新赛果卡片、榜单摘要、选手聚焦与下一比赛日 |
| 总赛程 | 按日期分组，展示时间、阶段、桌号、半庄和出场者；支持阶段、日期、选手/队伍关键词和状态；完赛可跳转赛果，待赛没有成绩 |
| 总赛果 | 仅发布结果，支持阶段/日期/选手/队伍、役满与积分调整筛选；每张卡列四人成绩，可查看详情 |
| 队伍榜 | 参考 ML 的积分、距前一名、距榜首、已赛/已排场数；罚分和带入单列；队伍名称可进入详情 |
| 个人榜 | 总积分、最高终局点数、均顺、头名率、连对率、避四率切换；阶段、资格场数、当前所属队伍和关键词；姓名进入详情 |
| 单场详情 | 四人顺位、当场队伍、终局点数、基础积分、个人罚分/净分、队伍贡献、规则版本、役满与公开处罚说明 |
| 队伍详情 | 队伍标识、统计摘要、当前及历史成员实际贡献、原始累计走势、最近赛果；不将带入分分摊给成员 |
| 选手详情 | 公开资料、表现指标、走势和最近赛果；不显示联系方式、报名内部备注等管理信息 |

个人赛不展示队伍榜导航；所有详情严格属于当前所选赛事，切换赛事返回新赛事首页，不带入旧赛事 ID 和筛选。找不到或尚未公开的对象显示不可用信息。

## 视觉和移动端

独立于后台侧栏表单布局：电脑端使用品牌页眉和顶部导航，首页采用赛事主视觉、赛果卡片、积分榜和选手聚焦；手机端使用底部导航，赛果卡片纵排，筛选适配窄屏，宽统计表在容器内滑动。
产品体系仍叫「欢雀楼赛事管理程序」；公众品牌使用“欢雀楼赛事”，避免将观众页面误认为后台。
队徽/头像尚未提供时用原创文字标识占位，不复制 ML 官方队徽或选手照片。

## 数据公开边界

公众端使用独立只读响应模型，不下载整个管理员数据包再靠 CSS/JavaScript 隐藏。

- 赛事与阶段必须公开才可出现在响应中。
- 排赛可单独公开：即使结果还在草稿状态，公开赛程可显示对阵与时间，但无比分、处罚详情或赛果链接。
- 榜单只统计公开且已发布的半庄、已确认处罚和已公开带入；不能通过客户端参数请求未发布结果。
- 处罚公开数额与公开说明，内部裁定备注、联系方式、账号、权限表、审核日志、后台附件和待审事件不下发。
- 正式服务在 API 层做状态和权限校验，任何猜测 ID、缓存旧响应、附件 URL 或跨赛事查询都不能绕过。
- 公布统计的来源版本、更新时间及更正标记；真实后台发布后失效相关公共缓存。阶段结算和成绩修改完成后展示端获取一致版本，不出现半张旧榜半张新榜。

正式数据流：管理员保存草稿 -> 审核/发布事务 -> 发布版本与公开数据模型 -> 公众只读 API -> 观众页面。更正走版本化发布，不在公众端直接改分。

## PWA 交付边界

正式版需 HTTPS、manifest、图标以及合适的资源缓存，支持浏览器添加到手机桌面。离线赛果要标注缓存时间；在线优先更新榜单，不向观众展示过期排名却标为实时。
当前原型完成电脑和手机网页布局，未实现桌面安装、推送、真实域名或生产部署；不能称为已经可安装的正式 PWA。

## 原型实现与验证

`site/` 是独立可预览目录。`build-public-data.js` 从虚构管理数据生成公开白名单文件 `site/data.json`；浏览器只加载该公开文件，不加载管理端脚本、表单或原始后台数据。
`public-data.test.js` 检查私有赛事/阶段、草稿结果、待审核处罚和内部备注不会进入公开数据，并验证公开待赛日程可见且不带比分。

本原型与管理端 v3 **尚未连接真实共享数据库**。管理端的内存演示编辑不会自动同步此站；目前用于审阅两端界面和公开数据边界。后续开发必须将两端接入同一真实后端发布链路。
本目录服务端副本位于 `/data/majiang/dev/app/design/prototypes/public-v1/`；仍保留开发/生产隔离和所有应用数据在 /data 的约束。

验收包括：页面无管理操作；私有数据不在页面源数据里；待赛无比分；仅已发布结果参与榜单；赛事切换无串数据；筛选可分享；选手、队伍和赛果详情可跳转；桌面与手机布局可操作。
